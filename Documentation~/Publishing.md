# Publishing

This editor-only package depends on ThreadLight Authoring and remains
independent of both ThreadLight Components and ThreadLight Builder. The public VPM listing
is published through GitHub Pages at:

`https://wolfy527.github.io/threadlight-mirroring/index.json`

Each release archive and its SHA-256 checksum are recorded in
`.vpm-listing/index.json`. Test VCC installation with ThreadLight Components absent,
then present as an unrelated customer package, and with the full ThreadLight Builder
present before every release.
